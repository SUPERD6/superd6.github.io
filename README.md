# Hongyu Deng — Academic website

Publications, academic background, engineering experience, and a downloadable CV.

## GitHub Pages

The website is published at https://superd6.github.io/.
Pushing to `main` builds the static site and deploys it through GitHub Actions.
Use Node.js 22 for local builds, matching the publishing workflow. On Windows,
Node.js 24 can crash when the framework exits after static prerendering.

```sh
pnpm install --frozen-lockfile
pnpm build:pages
```

The deployable output is `dist/client`. Only static website assets are published.
The existing `pnpm dev` and `pnpm build` commands retain the original Sites preview/build.

## Content maintenance

`app/profile.json` is generated by the local CV maintenance workspace. Update its
master record there and run `harness/maintain.py sync --site-only` for website-only
changes. Keep the downloadable PDF in `public/` synchronized with the verified CV.
